# FrozenCore AddOns 3.3.5a

FrozenCore's curated World of Warcraft 3.3.5a addon bundle.

## Included addons

- DBM and bundled DBM modules
- Details and bundled Details modules
- Dominos and bundled Dominos modules
- DungeonClear
- GearScoreLite
- OmniCC and OmniCC_Config
- UnBot
- YssBossLoot v1.0.4 with bundled libraries (required by UnBot)

YssBossLoot: [official WowAce release](https://www.wowace.com/projects/yssbossloot/files/455663).

## Install

Download the repository ZIP from GitHub, extract it, and copy the addon folders into:

```text
World of Warcraft 3.3.5a\Interface\AddOns
```

The addon folders are stored at the repository root so they can be copied directly into `Interface\AddOns`.
